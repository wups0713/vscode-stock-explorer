# 功能需求：新增股票 (Add Stock)

## 1. 功能描述與目標

本功能允許使用者透過關鍵字搜尋股票代碼或名稱，將欲追蹤的股票加入追蹤清單中，並持久化儲存至 `settings.json` 設定檔。

## 2. 使用者價值與背景

提供簡潔且具備即時比對功能的搜尋介面，讓使用者無需手動編輯複雜的 JSON 設定檔，即可輕鬆擴充其股票追蹤清單。

## 3. 功能需求清單

- **觸發入口：**
  - View Container 標題列按鈕：`+`（新增股票）。
  - 命令面板（Command Palette）：`Stock Explorer: Add Stock` (`stockExplorer.addStock`)。
- **搜尋介面與互動：**
  - 使用 VS Code 原生 `showQuickPick` 輸入框。
  - 使用者可輸入股票代碼（如 `2330`）或名稱（如 `台積電`）。
  - 系統即時比對符合條件的股票清單並顯示搜尋結果。
- **重複項目處理：**
  - 若搜尋到的股票已經存在於使用者追蹤清單中，選單項目旁標記 `(已新增)`。
  - 使用者若選擇已新增的股票，跳出 Notification 提示：「該股票已在追蹤清單中」，不重複加入。
- **資料持久化：**
  - 選擇未加入的股票後，系統更新 `settings.json` 中的 `stockExplorer.stocks` 陣列。
  - 新增之股票物件基礎格式：
    ```json
    {
      "id": "<股票代碼>",
      "provider": "<資料提供者>",
      "holdings": []
    }
    ```
  - 更新設定檔後，自動觸發 Tree View 刷新。

## 4. 主要使用場景與範例

- **場景 A：搜尋並新增台股**
  - 使用者點擊標題列的 `+` 按鈕，跳出 QuickPick。
  - 輸入 `2330`，列表顯示 `tse_2330.tw 台積電`。
  - 點選後，`settings.json` 自動追加該股票紀錄，Tree View 隨即顯示台積電的即時行情。
