# 功能需求：賣出股票部位紀錄 (Sell Stock)

## 1. 功能描述與目標

本功能允許使用者記錄賣出股票的股數，並依據先進先出（FIFO）原則扣減 `settings.json` 中 `holdings` 陣列的持股明細，進而更新 Tree View 中的持股數量與總成本。

## 2. 使用者價值與背景

投資者在賣出或減碼持股時，系統自動按 FIFO 扣減持股明細，精確反映減碼後的剩餘部位與成本。

## 3. 功能需求清單

- **觸發入口：**
  - Tree Item 右側 Inline Action 按鈕。
  - Tree Item 右鍵上下文選單：「賣出股票」。
  - 命令面板（Command Palette）：`Stock Explorer: Sell Stock` (`stockExplorer.sellStock`)。
- **互動輸入流程：**
  - **步驟 1：輸入賣出股數 (`amount`)**
    - 彈出 `showInputBox`。
    - 提示文字：`請輸入賣出股數`。
    - 預設值：無（空白輸入框）。
    - 格式驗證：必須為大於 0 的整數。
    - 防呆檢查：若輸入數量大於目前該股票的總持有數量（$\sum \text{amount}$），終止操作並跳出錯誤提示：`賣出數量超過目前持股總數 (現有: X 股)`。
  - **賣出單價輸入說明：**
    - **不需輸入賣出價格 (`price`)**，目前功能規格不計算已實現損益。
- **FIFO 扣減演算法與資料寫入：**
  - 依序自 `holdings` 陣列前端（最舊的買進紀錄）開始扣減數量 `amount`：
    1. 若當前紀錄數量 > 剩餘需賣出數量，當前紀錄數量扣減該數量，寫回 `settings.json`。
    2. 若當前紀錄數量 $\le$ 剩餘需賣出數量，移除該筆紀錄，並將差額繼續扣減下一筆紀錄。
  - 更新 `settings.json` 後刷新 Tree View。

## 4. 主要使用場景與範例

- **場景 A：部分減碼持股**
  - 現有 `holdings`: `[{"amount": 1000, "price": 500}, {"amount": 500, "price": 600}]` (總股數 1500)。
  - 使用者執行賣出，輸入數量 `1200`。
  - 第一筆紀錄 1000 股全部扣除並移除。
  - 第二筆紀錄扣除剩餘的 200 股，數量更新為 `300`，單價維持 `600`。
  - 更新後 `holdings`: `[{"amount": 300, "price": 600}]` (總股數 300)。

## 6. 約束條件與限制

- 賣出數量不得大於總持股數。
- 賣出操作僅影響 `holdings` 數量與總成本，不記錄與計算已實現損益。
