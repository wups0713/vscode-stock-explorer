# 功能需求：買進股票部位紀錄 (Buy Stock)

## 1. 功能描述與目標

本功能允許使用者記錄買進股票的交易明細（交易數量與成交單價），並自動更新 `settings.json` 中的 `holdings` 陣列，以做為未實現損益與平均成本計算之基礎。

## 2. 使用者價值與背景

投資者需要準確追蹤自己的買進成本。支援多筆買進紀錄（如分批建倉），能精確反映加權平均成本與真實投資績效。

## 3. 功能需求清單

- **觸發入口：**
  - Tree Item 右側 Inline Action 按鈕（`+` 或買進圖示）。
  - Tree Item 右鍵上下文選單：「買入股票」。
  - 命令面板（Command Palette）：`Stock Explorer: Buy Stock` (`stockExplorer.buyStock`)。
- **互動輸入流程：**
  - **步驟 1：輸入買進股數 (`amount`)**
    - 彈出 `showInputBox`。
    - 提示文字：`請輸入買進股數`。
    - 預設值：無（空白輸入框）。
    - 格式驗證：必須為大於 0 的整數。
  - **步驟 2：輸入買進單價 (`price`)**
    - 彈出 `showInputBox`。
    - 提示文字：`請輸入買進成交單價`。
    - 預設值：無（空白輸入框）。
    - 格式驗證：必須為大於 0 的正數（支援小數）。
- **資料儲存與結構更新：**
  - 將買進明細作為新物件推入（push）至 `settings.json` 中該股票的 `holdings` 陣列中：
    ```json
    {
      "amount": 1000,
      "price": 580.5
    }
    ```
  - 更新 `settings.json` 後，系統重新計算平均成本與未實現損益，並刷新 Tree View 節點。

## 4. 主要使用場景與範例

- **場景 A：分批買進股票**
  - 第一筆買進：輸入股數 `1000`，單價 `500`。`holdings` 新增 `[{"amount": 1000, "price": 500}]`。
  - 第二筆買進：輸入股數 `1000`，單價 `600`。`holdings` 更新為 `[{"amount": 1000, "price": 500}, {"amount": 1000, "price": 600}]`。
  - 系統展示平均成本為 `550`，總股數為 `2000`。

## 6. 約束條件與限制

- 輸入驗證失敗時（如輸入非數字或負數），應顯示錯誤訊息並中斷流程。
- 不提供當前股價作為預設填入單價，使用者必須手動輸入買進價格。
