# 功能需求：自動輪詢與狀態更新 (Update Stock State)

## 1. 功能描述與目標

本功能實現股票資料的自動輪詢與更新。僅在股票視圖容器（View Container）處於聚焦/可見狀態時，依據使用者在 `settings.json` 設定的秒數週期性發送網路請求更新行情數據，降低系統資源消耗並避免 API 頻率限制。

## 2. 使用者價值與背景

即時的股價變動是股票追蹤的核心需求。透過智慧型的輪詢機制（視圖隱藏時自動暫停），確保使用者獲得最新資訊的同時，不佔用背景網路與 CPU 資源。

## 3. 功能需求清單

- **設定項目（Configuration）：**
  - 設定鍵名：`stockExplorer.updateInterval`
  - 資料型別：數字（Number，單位為秒）
  - 預設值：`15`
  - 特殊限制：當設定值為 `0` 時，視為停用自動輪詢功能。
- **視圖狀態感應與輪詢控制：**
  - 使用者切換至股票 Tree View（View 變為可見）：
    1. 立即觸發一次即時數據更新。
    2. 若 `updateInterval > 0`，啟動定時器（Timer），每隔 `updateInterval` 秒輪詢一次。
  - 使用者切換至其他 Tree View 或隱藏側邊欄（View 變為隱藏）：
    1. 立即清除並停止定時器。
    2. 停止背景輪詢。
- **手動刷新支援：**
  - 提供手動重新整理按鈕（Refresh Action），使用者可隨時立即更新數據，且不影響自動輪詢計時。

## 4. 主要使用場景與範例

- **場景 A：開啟側邊欄自動更新**
  - 使用者點開股票總覽側邊欄，系統立即拉取最新股價，並依預設 15 秒間隔自動刷新畫面。
- **場景 B：切換視頁省電與網路資源**
  - 使用者切換回檔案總管（Explorer），股票輪詢定時器立即停止，避免在背景繼續發送 API 請求。
- **場景 C：停用自動輪詢**
  - 使用者將 `stockExplorer.updateInterval` 設為 `0`，視圖僅在開啟時或點擊「重新整理」按鈕時進行手動更新。

## 6. 約束條件與限制

- 輪詢機制必須嚴格依據 VS Code TreeView 的可見性事件（`onDidChangeVisibility`）觸發與終止。
- 網路請求例外或 API 異常時應具備容錯處理，避免輪詢崩潰。
